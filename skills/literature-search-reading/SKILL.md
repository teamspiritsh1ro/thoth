# 专业文献检索与阅读

默认交付真实文献、逐篇初读与初步综合。检索按原课件落实概念拆解、文献用语校准、组内扩展与组间组合、结果迭代，并在领域扩展任务中开展引文追踪；单纯拼接关键词后给链接不算落实课件方法。检索产出的最低要求是提供已核实的访问路径（期刊页、DOI、机构库或已有本地文件），不要求下载；这不是阅读的完成条件，初读仍按下述标准实际执行，不能只交链接。把文献当作学术对话：回应什么解释、提出什么主张、凭什么成立、对用户研究有什么用。默认用中文说明，保留必要英文术语。

## 按任务选择范围

| 请求 | 执行与参考入口 |
|---|---|
| 找论文、检索并初读、了解主题 | 读取[检索工作流](references/search-workflow.md)和[阅读工作流](references/reading-workflow.md)，执行到实际结果；不先交方案等待“继续” |
| 只读指定论文 | 读取阅读工作流，核对版本并按要求阅读；不强加主题检索或引文扩展 |
| 明确只要检索方案 | 读取检索工作流，给概念表、分入口方案和筛选标准；全部标为拟执行，不声称已检索或已读 |
| 我自己检索；根据这段话给关键词、检索式和检索网页；手动检索辅助 | 读取[手动检索辅助](references/manual-search-guide.md)及其中的网站入口；交付可直接使用的查询组合与操作步骤，由用户执行主题检索 |
| 领域入门、理论谱系、长期学习 | 在实际检索阅读基础上按需读取[追踪与知识框架](references/tracking-learning.md) |

已有主题时直接推进；主题确实缺失才询问，不从旧项目替用户选题。篇数、年份、地域和深度服从当前请求，不将教学案例或上次研究设计变成固定要求。

新增的手动检索辅助是明确“只给检索指导”的一种交付方式，不替代原有默认流程。它以用户本次发来的研究段落为输入，保留尚未确定的问题与概念，提供多组查询、对应网站和使用位置；不默认替用户执行主题检索、引文追踪或阅读。下文实际执行的证据判据在该模式中用于用户后续回传结果的核对，本轮查询一律标“拟执行”；查过网站/语法也不等于查过论文。用户要求代检索或回传论文要求初读后，再进入原流程。

## 核心流程：行动—证据—完成判断

记录可放在一个工作底稿或简短回复中，保留能回查的工具输出、来源链接和定位，不要求展示内部思维过程。表中证据是执行产物，不能靠填满表格替代操作。

| 行动 | 最小证据 | 可以怎样声明完成 |
|---|---|---|
| 检查可用工具与适用入口 | 实际入口、检查日期、观察到的页面/工具返回或具体错误 | 只说明已检查范围；未尝试不能归因为无权限，工具失败也不证明用户无订阅 |
| 检索前组织概念，随后以文献校准 | 对象、干预/现象、结果、机制、地域情境的简表；中英文表达、关系、来源/候选状态、必要/可选 | 有概念表且实际查询落实相关词组；仅生成词表或事后写布尔式不算已执行 |
| 执行组内扩展、组间组合并迭代 | 实际入口、日期、原样查询及对应概念组/变体、字段/筛选、调整理由、返回记录 | 查询确实执行，且能说明做了哪些词组替换与组合；近义词堆在同一串不算OR扩展，普通多词搜索与域名限定不冒充数据库布尔或字段检索 |
| 核验书目、去重、主动找全文 | 作者/题名/年份/版本、原出版或可信题录链接、纳入理由、获取结果 | 每项书目能回查；搜索摘要和推荐列表只算线索，未找到全文则如实保留摘要结果 |
| 按文章类型实际初读 | 独立的获取状态与阅读状态、实际阅读章节/页码、主张及证据定位 | 阅读范围支持卡片内容；下载、解析或OCR完成不等于全文已读 |
| 比较并交付 | 各篇论证、证据强度和主题关系；概念/指标可比性；具体缺口 | 声明限定在已核验材料与实际范围，不把选择性检索称为穷尽或研究空白已证实 |

概念初稿可包含待确认译法；先做少量术语校准查询，再开展主检索。经文献确认的词附题名/摘要/关键词位置；同义、近义、相关但不同概念分开。地域、机制、方法通常作为后续分支，不一开始全部设为必要条件。

数据库不可用时继续通过期刊、出版社、机构库和其他公开渠道执行；保留概念组织、迭代和来源核验。没有实际命中总数就写“未提供”；记录可在事后整理，但要对应真实调用和来源，不补造查询、次数、阅读范围或引文链。

## 按任务触发的要求

- **扩展领域认识的检索**：选关键种子，按任务规模做适量向后与向前追踪。按[引文追踪规则](references/search-workflow.md#引文追踪)记录种子、方向、候选、引用关系证据、核验链接和取舍。看到线索、核验论文、阅读论文、完成有界的一轮追踪是不同状态；某方向受阻单独说明。
- **定量初读**：围绕本次采用的主要结果核对指标定义及分母、样本与时间、模型和识别条件、关键结果及不确定性；未读到的部分留作缺口，不由显著性推出因果。
- **质性初读**：说明具体材料怎样支持分析命题、怎样回应理论，并保留反例和情境边界；理论名称与访谈方法名称不能代替论证。
- **精读或方法审查**：仅在用户要求或关键结论需要时加深。初读不默认扩展为逐页精读、完整方法审查或模型复现。

获取状态采用“题录／摘要／正文选段／完整全文可得”；阅读状态采用“未读／摘要初读／正文选段阅读／全文关键章节初读／全文精读”。两轴独立，具体判据见阅读工作流。范围写实际章节、表格或页码与阅读动作；“证据位于第6—11页”不能写成“第6—11页逐页读完”。

## 交付前核对证据

逐条核对交付书目、链接和版本；回查各篇核心论断的定位、概念/指标口径和阅读范围；核对每条引文追踪声明及最终完成声明。发现不一致时先补做可行操作，否则降低对应声明并列具体缺口。只有摘要时不补写它未提供的理论、样本、方法细节或证据；没有查看相关全文不能断言“作者未报告”。

默认交付顺序：文献及来源 → 简明论证阅读与相关性 → 跨篇认识和精读优先级 → 精简执行记录与限制。可从[工作底稿](assets/literature-workbench.md)选择适用模块，短任务不制造整套文件。自检结论应能指向证据或修正，不使用一张全勾选表证明有效。

## 可选工具与来源

不要求每次使用WoS、CNKI、截词、邻近算符、网络图或全部工具；实际使用时核对当前官方语法。AI候选概念、词频/中心度和“研究空白”不自动成为已验证事实。期刊收录与学校目录按版本核实；期刊等级不替代文章证据。

全文优先用已有图书馆权限、出版社、机构库和作者公开版本。订阅、定时追踪、上传论文或写入外部文献库只在用户请求时进行；技能不要求付费、子智能体或额外账号。

方法来源为两份主课件及配套材料；[来源说明](references/source-notes.md)区分课程方法与执行补充，[文件指纹](references/source-manifest.json)记录实际来源。需要课堂示范时读[阅读示例](references/reading-examples.md)；维护技能时用[验证场景](references/validation-scenarios.md)，普通检索无需加载测试材料。
