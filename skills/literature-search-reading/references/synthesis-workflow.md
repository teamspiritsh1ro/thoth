# 多篇综合：把论证放在可比较的范围内

适用：概念辨析、理论谱系、解释框架、批判性综述或复杂的跨篇比较。简单任务可用短段落完成；不强制每次输出完整矩阵。只使用本轮实际阅读与核验的材料，不能把推荐或待获取的文献算作已读。

## 先对齐比较对象

明确要比较定义、解释、机制、结果还是方法，列参与比较的文献ID和实际阅读范围。检查下列适用维度；缺失就保留未知，不为填表补造：

| 维度 | 判断问题 |
|---|---|
| 概念与定义 | 同名是否同义；近义、上下位、相关不同概念是否被混用 |
| 研究对象和单位 | 研究个人、组织、地区、过程还是概念；结论针对谁 |
| 情境、尺度与时期 | 制度、群体、时间和层级是否可比；不适用项可略 |
| 结果与测量口径 | 指标、分母、单位、基准、比较对象是否一致 |
| 设计与证据类型 | 理论推演、质性材料、描述、相关或因果识别支持什么 |
| 问题及推论边界 | 是否回答同一个问题，结论能推广到哪里 |

有了可比基础才讨论支持或冲突。摘要缺少口径时写“可能存在条件差异，待全文核对”，不凭相反措辞认定互相证伪；理论论文没有样本不等于缺乏理论价值。

## 用论证作用组织材料

按证据判断各篇承担的作用：概念定义或理论来源、概念发展/理论桥梁、解释过程、经验检验、反例与限制。作用可重叠，不凭声望、被引量或发表先后建立谱系。理论借用、修正、批评与继承需要所读文本或核实引文关系；摘要只支持其中明确写出的关系。

每项主要判断区分三层：**作者明示的主张**、**当前所读证据支持的判断**、**综合者提出的解释或待检验假设**。对本研究的借用建议不是原作者结论，研究议程也不等于已证实的文献空白。二手转述保留已读来源和原著未核读标记。

用户需要解释“如何/为何发生”时，可用“前提条件 → 主体行动/关系或过程 → 变化 → 边界/反馈”作简短比较支架，逐段附来源；不是将多篇结果拼成已证实的因果链。未报告的机制、识别条件或竞争解释留作缺口，不由模型名称、显著相关或单个案例推出因果。

## 形成有限的综合结论

区分相互支持、关注不同环节、互补、条件性差异、可能冲突待核、证据充分的矛盾。先考虑概念、样本、制度、时段、尺度及证据强度能否解释差异，并保留反例和竞争解释。

按任务交付简明的概念对齐、各篇论证作用、一致/分歧、目前可支持的命题与精读优先级。每个跨篇核心命题都能回到所依赖文献及证据位置；不要求固定六张表。只有摘要时把结论限于摘要明示层次；阅读状态标实际完成的摘要初读，获取状态独立按材料可得性记录，不能把已有全文降成“只有摘要”。

理论基础仍有缺口时，先说明关键原始文本、书籍/章节或争论来源的已读、二手、未决范围；在用户允许扩展检索时才按[两类发现](search-workflow.md#研究问题类与理论基础类)补做。仅基于指定材料比较时止于材料内结论，不把缺口自动变成新任务。
