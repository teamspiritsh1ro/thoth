# 阅读：用实际范围支撑论证判断

课件依据：阅读第3—27页，尤其第5—7页的定量框架、第15—20及22—25页的理论对话与材料论证。下面的两轴状态和执行证据是为可核查阅读补充的规则。配套案例见[阅读示例](reading-examples.md)。

## 获取与阅读分两轴

先核对题目、作者、版本、文献类型及文件完整性；获取来源可以是原PDF、HTML全文或摘要。获取状态可更新，阅读状态只随实际阅读更新。

| 获取状态 | 含义 |
|---|---|
| 题录 | 只有书目，搜索片段不算完整摘要 |
| 摘要 | 可核对完整摘要，尚无正文 |
| 正文选段 | 有正文片段/预览，未确认完整正文可读 |
| 完整全文可得 | 正文完整可访问或已下载；补充材料是否可得另记 |

| 阅读状态 | 行动与最小证据 | 不足时的处理 |
|---|---|---|
| 未读 | 仅核题录/获取文件，尚未阅读内容 | 不生成冒充阅读的卡片 |
| 摘要初读 | 读完整摘要；链接及摘要位置，概括其中明示的问题/方法/结论 | 搜索片段不足则回到未读；缺细节不补写 |
| 正文选段阅读 | 实际读了某些正文段落/图表；列章节或页码与对应主张 | 即使完整PDF已下载，未覆盖关键论证仍用此状态 |
| 全文关键章节初读 | 全文可得，按文章类型读问题/对话、理论或概念、方法或论证路径、关键证据、结论；有下述论证短卡和定位 | 关键部分缺失则标选段阅读并说明；不表示逐页读完 |
| 全文精读 | 按当前要求深入核对全文主要论证和证据、矛盾及适用边界，列实际覆盖与未读附录等 | 不由文件下载、全量解析或初读卡自动升级；不等于模型复现 |

阅读记录使用`文献ID｜来源/版本｜获取状态｜阅读状态｜实际章节/页码/表格及阅读动作｜证据定位`。例如“精看§3.2与表2；浏览§4标题；未读附录”，不要用一个宽泛页码区间掩盖动作差异。PDF注明物理页或刊页；HTML用节标题、表号或可复查段落。长页工具只返回部分内容时，查找命中句并不证明周围章节已读，应打开相关上下文。

整份文本下载、提取或OCR只是获取/解析动作。证据所在页范围不等于逐页阅读范围。关键图表、公式或多栏解析有歧义时回页面视觉核对；不影响本次结论的图无需全部渲染。

## 初读：做简明论证短卡

全文可读时，先读摘要和结构，再查看引言、理论或框架、方法、支撑本次主要结论的证据、结论。按文章类型调整，不强迫理论论文采用实证章节。初读聚焦能判断相关性和结论强度的主要论证，不逐项穷尽全部结果。

| 要回答的问题 | 读什么、留下什么 |
|---|---|
| 回应什么既有解释或争论？ | 引言/综述中的具体观点和对话对象，区分借用、批评与补充；不能只写理论名 |
| 作者认为哪里不足？ | 作者提出的缺口及位置；与独立验证的研究空白区分 |
| 提出什么问题、命题或解释？ | 说明概念之间如何关联、预期怎样回答问题 |
| 用什么证据支持？ | 抽出与主论点直接相关的结果/材料，给章节、页码或表格定位 |
| 证据支持多强的结论？ | 区分描述、关联、机制解释、因果识别；指出最影响判断的限制或未核对项 |
| 对用户研究有什么用？ | 说明可借鉴内容及条件、需重新检验与不可直接移植内容 |

可用一小段和一条主张—证据链完成，不为填满模板虚构信息。如果材料只有摘要，六问只答其中明示内容，其余写“摘要未提供/待全文核对”。摘要复述不能升级为已审查理论或证据；“所读部分未提供”不能扩大为“作者未报告”。

### 定量文献

围绕要引用的主要结果核对：

- 概念与指标：定义、方向、单位；比例的分子/分母和空间/时间口径，避免把意愿、行为、潜力、面积或产量混作同一结果。
- 样本与时间：总体/样本、回收/有效数量、排除规则、地区与时期；无法获取时留下具体缺口。
- 模型与识别：方法如何回答问题，关键识别条件是否讨论/检查；“使用了某模型”不是识别成立的证明。
- 关键结果：对应表/图、方向与大小、适用比较、区间/标准误等；只看摘要百分比时不能称已核对结果表。

初读核查的是本次采用的主要结论，不默认检查所有稳健性或重跑模型。发现数字或口径矛盾时保留双方定位，暂不作依赖该矛盾的精确推断。初读未核验某假设时写清，不能推断该论文必然有效或无效。

### 质性文献

从主论点选代表性证据，连成“材料/观察 → 作者的分析命题 → 对既有解释的支持、修正或挑战”。注明实际材料位置，解释为什么支持该命题及还不能支持什么。语录不能独自证明理论贡献，理论标签也不能替代这种连接。

核对案例选择、材料来源、时间与分析过程到初读所需程度；记录能改变结论的反例、矛盾或张力。不补造未见的访谈样本、编码、饱和度或反事实。案例机制解释不自动推广到其他地区。

### 综述、理论论文和社论

综述关注如何组织争论、选择文献及推导前沿；其对原研究的转述注明二手来源。理论论文看概念关系、推演依据与适用边界；没有计量样本不算缺陷。社论/专刊导言用作议程线索，具体实证判断回对应研究。文章类型决定深度，不以期刊等级代替评价。

## 精读与多篇综合（按任务加深）

用户需要精读时，再逐段识别背景、理论借用、批评对象、作者主张与证据；追查关键原始引文，检查相互矛盾的材料与替代解释。英文长句先辨认谁主张、转折和限定条件，辅助译文不替代原文。

多篇比较先对齐概念、指标分母、对象、尺度、时期和证据类型，再讨论一致或分歧；若差异来自口径，不能直接说理论互相否定。区分作者自述贡献、当前证据支持的贡献和自己的解释。精读优先级按研究相关性、理论/方法价值与可核查证据决定，研究空白只写成待检验候选。

## 交付前回查

对每篇卡片回到书目与核心证据位置，确认来源链接指向对应版本、读到的内容支持所写结论、状态没有升级。特别抽查数量/分母、因果措辞、引文追踪与完成声明。可补读则补读；不可补读则收窄结论并列出缺口。记录实际发现及处理，不用统一“通过”代替回查。
