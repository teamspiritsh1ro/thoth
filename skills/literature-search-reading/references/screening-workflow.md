# 批量题录与摘要：从导入到核读

适用：用户已有数据库导出、文献库、题录或摘要，要求去重、筛选、短卡或交给后续综合。直接处理实际材料，不默认重跑主题检索。仅要预筛就止于预筛；要求初读则实际核读可读材料。原有[阅读标准](reading-workflow.md)不变。

## 接收与身份核对

记录文件/批次、记录分界、编码、实际解析条数和可用字段，检查末条是否完整、摘要是否缺失或截断。保留原始输入和可回查ID。查询、数据库/子库、日期、条件来自用户时标“用户提供”；缺少就写未提供。导出条数、数据库命中总数、下载文件数各自计数，不能互相倒推。只在确实影响判断且现有材料无法解决时询问用户。

数据库记录号用于本库记录级去重；不同库的同号不能直接合并。DOI规范化后联合题名、作者、年份和版本判断跨记录疑似同文。提前在线版、正式版、修订版保留关联与合并依据；勘误、回应及同名不同作品不按题名或母文DOI盲目合并。保留原记录到作品ID的映射、保留项、冲突和未决项；证据不足只标“疑似重复”，不报已确认独立作品总数。

书籍无数据库记录号不因此丢弃；记录作者/编者、版次、ISBN、章节DOI、母书及本地ID。相同文件哈希只证明副本相同，不同ISBN也可能只是不同介质或版次。章节与母书是关联单位，不直接互相去重。阅读细节见[书籍与章节](reading-workflow.md#书籍与章节)。

## 分开记录筛选阶段与阅读

S编号仅用于批量摘要处理，普通单篇不必使用；是否纳入是另一项判断，不由阶段自动决定。

| 阶段 | 达标动作与最小证据 | 不能升级的声明 |
|---|---|---|
| S0 已导入 | 解析记录及字段、来源批次、稳定ID | 不代表读过摘要或核验书目 |
| S1 规则或模型预筛 | 按明确规则匹配、打分或排序，保留依据与候选 | 分数和关键词命中不代表逐篇读过完整摘要 |
| S2 摘要相关性核读 | 实际读完整摘要，逐篇给纳入/排除/待定及可定位的摘要依据 | 不代表完成论证卡、全文核验或理论审查 |
| S3 摘要论证短卡 | 完成S2，按摘要明示内容整理主要主张、证据类型、适用范围和缺口 | 不代表全文已读，也不补写摘要未给的信息 |

可直接核读到S2/S3，不为补齐编号伪造先前预筛操作。人工或智能体均需实际查看相应内容；核读方式如实记录。无完整摘要者不授予S2/S3，缺摘要不等于无关；实际阅读其正文或书籍章节时，另记正文相关性依据及原阅读状态，不强造摘要，也不要求先通过这条摘要路径。

最低记录：`记录/作品ID｜来源定位｜实际筛选阶段或正文处理说明｜相关性决定及理由位置｜获取状态｜阅读状态/实际范围`。摘要已核读时才记“摘要初读”；全文在手但仅读摘要，获取仍是“完整全文可得”。来源身份尚未核验与阅读过所给文本也要分开说明。

相关性可分“直接相关”“理论/背景重要”“待定需核读”“低优先级待复核”“有依据排除”。理论基础的作用按[两类发现](search-workflow.md#研究问题类与理论基础类)判断；不因未命中特定对象词就排除基础理论。低分、未入核心集、缺摘要都不是已核读排除。系统综述另外服从其正式纳排协议，此流程不替代协议。

## 计数、复核与交付

先报告原始记录、记录级去重、疑似同文与未决数、可用摘要数；确认作品身份后再报告作品数。S0–S3可按“当前最高已完成阶段”互斥计数，或报告累计达到数，但注明口径；累计数不能相加。无摘要而已处理正文的项目单列，未决和未读数保留。相关性类别若多标签，说明不可相加为总数。

小批次可逐项复核；大批次按工作量选定并报告实际抽查范围，优先查高分核心、低分理论候选、缺摘要、疑似重复及争议排除。抽查的是判断与原始内容是否相符，不是有没有填字段；发现不稳定就调整规则或扩大核读。抽样通过不能把其余预筛记录批量升级为已核读。

迭代时记录规则版本及新增、移出、合并、重分类的具体理由，保留原决定。交付顺序为“实际处理数量与层次 → 筛选结果/短卡及证据 → 待定与后续阅读”；少量材料可用一份简表，无需另建数据库或大量文件。多篇解释关系需要综合时进入[综合流程](synthesis-workflow.md)。
