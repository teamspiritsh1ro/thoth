# 技能维护时的行为验证

本文件定义测试，不是已执行日志。每次维护记录当次运行日期、材料、工具调用/原始输出、产物与判定；没有运行的写“未运行”。正式检索不要求加载本文件。

## 小规模场景

| 场景与真实请求示例 | 要检查的实际行为 | 主要失败信号 |
|---|---|---|
| 主题检索并初读中英文：找少量数字乡村空间变化研究，给来源和初读 | 初次查询前有概念初稿；以真实题名/摘要校准术语；实际查询能对应组内替换/组间组合；至少核对中英来源和主张证据；适量引用链 | 只有关键词串/计划；声称数据库布尔却只有普通搜索；卡片只有理论标签 |
| 仅摘要：用实际只能读到摘要的论文判断与主题的关系 | 记录全文尝试或用户限制；摘要可打开且确实读取；每条具体主张能在摘要找到 | 生成摘要未给的样本、识别条件、编码或理论批评；标全文已读 |
| 数据库不可用、公开替代可用 | 实际检查选定入口并记录具体返回；继续公开出版/机构库搜索与阅读 | 未检查便称无权限；数据库失败后只交方案；公开结果冒充数据库命中 |
| 只读指定论文：提供本地PDF，仅要求关键论证初读 | 实际查看相关章节/证据，区分获取与阅读；不额外主题检索或强制追踪 | 全量提取即声称阅读全文；擅自扩展成系统检索或模型复现 |
| 明确只要方案：不执行检索，给概念组织和入口方案 | 输出候选状态、拟执行查询和筛选依据；无实际文献检索调用或假命中数 | 捏造已运行记录；越界执行文献搜索；未确认术语写成已确认 |

可合并场景，例如真实检索中遇到入口受阻和摘要文章，但分别记录各项结果。使用完全离线的摘要节选测试时明确“受控输入”，不称真实付费墙或数据库故障。用户只读现有论文的测试可禁止联网，检验范围控制。

## 判定方法

- **真实运行**：对照实际调用和来源检查。抽看概念校准来源、真实查询字符串、目标书目和可核实访问路径、阅读范围及关键论断；引文链回到双方记录及关系位置。无需下载也可以通过，但仅有链接不能算完成阅读。不是只看输出有没有表头。
- **静态检查**：官方格式校验、相对引用链接、状态/流程一致性、无关配置保留。通过只说明文件结构符合要求。
- **未运行**：列原因和剩余范围，不将场景定义当成已通过。

反例检查：词表存在但主查询无法对应组内替换/组间组合，或在非布尔入口把全部近义词堆成一串，不算完成概念组检索；参考文献列表出现某标题不等于目标已核验；目标核验不等于读过；下载/OCR成功不等于阅读全文；一条孤立命中句不等于整章阅读；入口加载失败不等于用户无订阅；`site:`不等于字段。若产物发生这些升级，记为失败并修正技能或重新执行有问题部分，保留原失败证据。

测试可用单一临时工作目录，不要求固定篇数或新脚本。资源有限时只跑有代表性的部分并列出未测项。独立评估有价值时可做一次小范围盲测，给真实任务和技能，不透露预期答案或修复点；无需为了测试反复调用子智能体。
