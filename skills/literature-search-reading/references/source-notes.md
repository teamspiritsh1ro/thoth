# 来源、阅读覆盖与使用边界

创建日期：2026-10-28。用途：把教学材料的方法提炼为可复用的 Codex 技能。方法主体来自课件；为执行可追溯性补充了日志、书目核对、证据状态和适用范围判断。

## 输入来源

方法依据为《专业文献检索》（148页）和《专业文献阅读》（27页）两份课程讲义及配套材料。检索课件封面标注“华南人文地理与城市发展研究中心”“地理科学与遥感学院”；未据此推定具体作者或发布授权。主课件的页数、SHA-256和配套材料文件名见[来源清单](source-manifest.json)。

本仓库发布整理后的执行指令和模板，不分发原始课件、论文全文、邮件、私人执行记录或本地路径。课件和论文的权利归原权利人，仓库许可证不覆盖这些外部材料；本项目不代表课程提供方或OpenAI的认可。详见仓库根目录的第三方材料说明。技能运行不依赖原压缩包。

## 覆盖与本次更新依据

初次创建时生成了主课件的文本提取和部分截图，配套论文用于核对类型、章节与示例；这些解析/截图记录本身不证明逐页阅读全文。配套论文并未全部逐字精读或独立复现；CSSCI扫描目录仅检查版本标题，未逐条核验收录。

2026-10-28本次更新重新从方法来源压缩包解压并比对SHA-256：压缩包及两份主课件均与来源清单一致。实际阅读检索课件第13—25、58—65、71—89、92—98、105—110页返回的文本，以及阅读课件第1—27页返回的文本；另视觉查看检索第87页、阅读第14及19页。部分纯图页无提取文本，不把这些页算作已视觉阅读。未重新精读全部配套论文，未执行课堂截图中的查询。

维护时另对照实际执行记录检查检索和阅读声明。该类记录用于发现执行缺陷，原课件用于核对方法；私人执行材料不随开源版本发布。

教学方法以概念组织和学术对话为主；技能中的状态名称、最小日志、完成判据及测试场景是本次工程化补充，不能归为教师原话。课件中的AI输出、课堂练习指令、期刊名单及数量不作为已验证事实或用户新任务。

维护延续至2026-10-29：依据用户补充，将访问路径明确为检索产出的最低要求，下载可选，阅读标准不变；课件核心方法仍为执行要求。小规模真实测试显示概念表本身不能保证组内扩展落实，进一步要求实际查询对应概念组与词语替换，避免将近义词堆在同一查询中冒充OR。详细测试记录独立保存，不把测试案例写成通用研究限制。

## 对课件内容的使用取舍

保留课程的核心思路和可操作方法，对容易造成实际误用的表述加上边界：

| 教学材料中的表述或示例 | 本技能的处理 |
|---|---|
| 穷尽文献、必须某字段、核心期刊降噪等强调式教学措辞 | 按普通探索、理论阅读、系统综述等目的选择；报告检索范围，不默认穷尽 |
| 期刊等级/知名作者的优先选择 | 作为阅读入口和线索，不能替代对相关性、方法与证据的评价 |
| 邻近算符“捕获强理论关联” | 只保证文本距离条件；理论关系和因果关系必须阅读判断 |
| CNKI“主题”字段的描述 | 以当前界面帮助为准，不固化为全文匹配；不给未经核实的专用语法 |
| 多个概念用 OR 扩展 | 标明近义、上下位和不同流派术语，不能推定概念完全等价 |
| 社论一律不经过传统同行评议 | 不作普遍规定；看具体期刊和文章类型说明 |
| AI 声称语义中心度、核心概念排名 | 无原始样本与计算不能报告为计量事实；保留为教学演示 |
| 课件中的第三方镜像和下载网站 | 不作为默认依赖；优先图书馆、出版社、开放获取和机构库 |
| 辅助译读中的书目拼写、地名或卷期差异 | 回原论文及出版者记录核对，保留版本差异 |

这张表说明技能编写时的使用边界，不声称对整份课件完成了学术审稿或事实纠错。

## 期刊目录必须带版本

本包提供 `CSSCI(2025-2026)扩展版来源期刊目录.pdf`、`CSSCI2025发布稿（正版）.pdf` 和 `广大[2025]67号（广州大学关于印发《广州大学人文社会科学中文一类重要期刊目录（2025）》的通知）.pdf`。文件名中的“正版”不能替代官方来源验证。

回答某刊是否收录、属于哪一类或是否满足学校考核时，分别核查该年度官方 CSSCI/Clarivate 记录与适用的学校文件，记录查询日期、目录年份、期刊名与 ISSN。CSSCI 来源、CSSCI 扩展、学校中文一类、JCR 分区及其他评价体系不要互换。
